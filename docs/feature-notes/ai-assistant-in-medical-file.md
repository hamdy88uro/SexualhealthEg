# مساعد ذكي (AI) داخل الملف الطبي

> ملاحظة مطلوبة محفوظة للتنفيذ لاحقًا — لسه معمول عليها حاجة في الكود، ده توصيف للمطلوب بس.
> ظهر في الموك أب كزرار مكانه محجوز فقط: "✨ اسأل المساعد الذكي عن الحالة دي (قريباً)" جوه سكشن C/O.

## المطلوب

زرار/أداة جوه شاشة الملف الطبي، يديله الدكتور سؤال عن الحالة (زي "إيه الكلام المناسب أقوله للمريض؟"،
"فيه انفستجيشن ناقصة؟"، "إيه خيارات العلاج المناسبة هنا؟")، والأداة ترد بناءً على بيانات المريض
المسجلة فعليًا في الملف (الشكوى، الهستوري، الفحوصات، التشخيص لحد دلوقتي) — مش رد عام.

## الفكرة التقنية (للتنفيذ لاحقًا)

- الاستدعاء بيتم من **السيرفر/الباك إند** (زي Cloud Function على نفس مشروع Firebase)، مش من جوه
  التطبيق مباشرة — عشان الـ API key متتسربش أبدًا على جهاز العميل.
- التطبيق يبعت للباك إند: `patientId` + السؤال، والباك إند هو اللي يجمع الـ context المسموح بيه
  (الشكوى، الهستوري، الفحوصات، ...) من Firestore ويبنيه في prompt، ويبعته لـ LLM API (زي Claude API).
- الرد بيرجع للتطبيق ويتعرض جوه نفس الشاشة — بدون ما يتسجل تلقائيًا كجزء من الملف الطبي الرسمي
  إلا لو الدكتور اختار يحفظه (عشان نفرق بين اقتراح AI وبين قرار الدكتور الفعلي).
- كل استدعاء له تكلفة بسيطة (سنتات) — ممكن تتحط كمصروف تشغيلي ضمن سعر الكشف، أو نتابعها كـ usage
  لكل حساب عيادة لو عايزين نراقب التكلفة الشهرية.
- لازم يحترم نفس صلاحيات الرؤية الموجودة (Owner/Doctor بس) — مفيش طريقة لأي رول تاني يستخدم الأداة دي
  أو يشوف ردودها.

## الحالة

⏳ لسه فكرة محفوظة — لم يبدأ التنفيذ. الزرار في الموك أب مجرد مكان محجوز (placeholder) بعلامة "قريباً".
